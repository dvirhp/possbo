# Client Architecture — PostIt Frontend

## Tech Stack

- **React 18.2** — functional components, hooks only
- **Vite 5** — dev server (:3000), build tool
- **React Router 6** — client-side routing
- **Axios** — HTTP client with interceptors
- **Hebrew UI** — RTL direction, all text in Hebrew

## Routing

```
/               → Landing (public)
/login          → Login (redirects to /dashboard if authenticated)
/register       → Register (redirects to /dashboard after success)
/dashboard      → Dashboard (protected, redirects to /login if no session)
/my-groups      → MyGroups (protected)
/create-post    → CreatePost (protected, accepts state.group for pre-selection)
/group/:id      → GroupDetails (protected, expects location.state with group data)
```

## Authentication Flow

```
┌─────────────────────────────────────────────────────────────┐
│ http.js — Axios Instance                                     │
│                                                              │
│ • Stores accessToken in memory (NOT localStorage)           │
│ • Attaches Authorization: Bearer <token> to all requests    │
│ • On 401 response → auto-calls /api/auth/refresh            │
│   → If refresh succeeds: retries original request           │
│   → If refresh fails: clears token, redirects to /login     │
└─────────────────────────────────────────────────────────────┘
```

### Login Flow:

1. User submits email + password
2. `authAPI.login()` → server returns `{ accessToken }` + sets httpOnly cookie
3. `setAccessToken(token)` stores in memory
4. Navigate to `/dashboard`

### Page Load (protected pages):

1. `useEffect` → calls `authAPI.refresh()`
2. If succeeds → token restored, load user data
3. If fails → navigate to `/login`

## Pages Detail

### Landing (`/`)

- Public page explaining the product
- Nav bar: logo (left), הרשמה (prominent) + התחברות buttons
- Hero section: headline, subtitle, 4 feature cards, CTA buttons
- Auto-redirects to dashboard if already authenticated

### Dashboard (`/dashboard`)

- Sticky header: logo, user name, logout button
- **Action cards** (2 columns):
  - "צור פוסט חדש" → `/create-post`
  - "הקבוצות שלי" → `/my-groups`
- **Recent posts section**: lists PublicationHistory (last 50)
  - Shows group name, post preview, status badge, date

### CreatePost (`/create-post`)

- Receives optional `state.group` (pre-selected group from GroupDetails)
- **Post form**: textarea, image upload, location picker, anonymous toggle
- **Group selector**: checkbox list of all saved groups
  - Pre-selected group shown with note
  - Multiple groups can be selected
- **Publish**: sends to all selected groups in parallel (`Promise.all`)
- **Results screen**: per-group success/failure with links

### MyGroups (`/my-groups`)

- Loads saved groups from DB on mount
- "Refresh" button → scrapes Facebook for latest groups
- Uses `GenericList` component with search/filter
- Each group links to `/group/:id` (passes group data via state)

### GroupDetails (`/group/:id`)

- Shows group name, image, Facebook link
- Actions: capture screenshot, publish post (inline form), multi-group publish
- "פרסם בקבוצה זו + קבוצות נוספות" → navigates to CreatePost with group pre-selected
- Posts history for the group

## Services Layer

### `http.js` — Base Axios Instance

```javascript
// Creates axios instance with:
baseURL: "http://localhost:5001/api"
withCredentials: true  // Send cookies

// Token management:
setAccessToken(token)   // Store in closure
clearAccessToken()      // Clear on logout

// Interceptors:
request  → attach Bearer token
response → on 401, try refresh, retry original
```

### `api.js` — High-Level API

```javascript
authAPI.register(email, password, name, fbAppId, fbSecret);
authAPI.login(email, password);
authAPI.getMe();
authAPI.refresh();
authAPI.logout();

groupsAPI.bootstrapSession();
groupsAPI.scrapeMyGroups();
groupsAPI.getMyGroups();
groupsAPI.getSavedGroups();
groupsAPI.publishToGroup(url, text, image);
```

### `groupsService.js` — Groups + Scheduler

```javascript
groupsService.getSavedGroups();
groupsService.scrapeMyGroups();
groupsService.getGroupPosts(groupId);
groupsService.bootstrapSession();
groupsService.getPublicationHistory();
groupsService.getJobs();
groupsService.schedulePost(data);
groupsService.cancelJob(jobId);
groupsService.getNotifications();
groupsService.markNotificationsRead();
groupsService.getSessionStatus();
```

### `publishService.js` — Publish

```javascript
publishService.publish(
  groupUrl,
  text,
  imageFile,
  groupName,
  anonymous,
  location,
);
publishService.getHistory(groupUrl);
```

## Components

### `GenericList`

Reusable list with:

- Search/filter input
- Items rendered with name, optional image
- Click navigates to `basePath/:id` with item data in state
- Supports external URL links

### `LocationAutocomplete`

- Debounced input → queries OpenStreetMap Nominatim API
- Dropdown with location suggestions
- Returns selected location string

## Styling Conventions

- **One CSS file per page/component** — no CSS modules, no CSS-in-JS
- **RTL by default** — `direction: rtl` in App.css
- **Design system colors**:
  - Primary gradient: `#667eea → #764ba2`
  - Error: `#dc2626` on `#fef2f2`
  - Success: `#155724` on `#d4edda`
- **Responsive** — media queries at 768px and 600px breakpoints
- **Card-based UI** — `border-radius: 14px`, `box-shadow` for elevation

## Testing

```bash
npm test              # Run all tests
npm run test:watch    # Watch mode
npm run test:coverage # Coverage report
```

Framework: Vitest + @testing-library/react + jsdom  
Test location: `client/src/test/` — mirrors page/component/service structure

### Test Conventions:

- Mock axios/http in service tests
- Render components with MemoryRouter for routing tests
- Use `screen.getByText()` for Hebrew text assertions
- Mock `useNavigate` for navigation assertions

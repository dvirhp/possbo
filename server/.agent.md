# Server Architecture — PostIt Backend

## Entry Point

`src/index.js` — Express app setup, middleware chain, route registration, scheduler start.

```
Request Flow:
  → CORS → JSON parser → Cookie parser → JWT user loader → Routes → Error handler
```

```
server/src/

├── config/
```

## Authentication Flow

```
Register:
  POST /api/auth/register
  → hash password (bcrypt, 12 rounds)
  → encrypt FB credentials (AES-256-GCM)
  → create User
  → return { accessToken } + set refreshToken cookie

Login:
  POST /api/auth/login
  → verify password
  → return { accessToken } + set refreshToken cookie

Token Refresh:
  POST /api/auth/refresh
  → read refreshToken from httpOnly cookie
  → verify → generate new accessToken
  → return { accessToken }

Protected Routes:
  Authorization: Bearer <accessToken>
  → middleware extracts user → sets req.user
```

### Token Config

- Access token: 15 minutes, signed with `JWT_SECRET`
- Refresh token: 7 days, signed with `JWT_REFRESH_SECRET`, stored in httpOnly cookie

## Facebook Automation (`utils/facebook-automation.js`)

All Facebook interaction uses **Playwright** with stored browser cookies (no Graph API for posting).

### Key Functions:

| Function                                          | Purpose                                                                       |
| ------------------------------------------------- | ----------------------------------------------------------------------------- |
| `bootstrapFacebookSession(userId)`                | Opens visible browser → user logs in manually → saves cookies encrypted in DB |
| `loadUserStorageState(userId)`                    | Decrypts stored cookies → returns Playwright storage state                    |
| `saveUserStorageState(userId, state)`             | Encrypts cookies → saves to user.facebookStorageState                         |
| `scrapeMyGroups(userId)`                          | Headless browser → navigates to /groups → extracts group list                 |
| `publishToGroup(groupUrl, text, imagePath, opts)` | Headless → navigates to group → creates post → returns postUrl                |
| `getStorageState(userId)`                         | Returns raw decrypted state for validation                                    |

### Session Lifecycle:

1. User clicks "Connect Facebook" → `bootstrapFacebookSession` opens browser
2. User logs in manually → cookies saved encrypted
3. Every 3 days → `session-keepalive.js` validates cookies still work
4. If expired → nullifies `facebookStorageState` + creates notification

## Background Jobs (`jobs/`)

Started via `startScheduler()` called from `index.js` after server listen.

| Job                        | Interval   | Purpose                                              |
| -------------------------- | ---------- | ---------------------------------------------------- |
| `processPublicationJobs()` | 60 seconds | Find PENDING jobs, lock, publish, handle retries     |
| `generateScheduledJobs()`  | 5 minutes  | Create PublicationJob entries from PostGroupSchedule |
| `runSessionKeepAlive()`    | 3 days     | Validate all users' Facebook sessions                |

### Publication Job Lifecycle:

```
PENDING → lock (optimistic) → RUNNING → publish via Playwright
  ├─ Success → SUCCESS + PublicationHistory record
  └─ Failure → retry with exponential backoff (10/20/40 min)
      └─ Max 3 attempts → FAILED + Notification to user
```

### Optimistic Locking:

```sql
UPDATE publication_jobs
SET status='RUNNING', locked_at=NOW(), locked_by=<workerId>
WHERE id=<jobId> AND status='PENDING' AND locked_at IS NULL
```

## Database Schema (Key Models)

### Core:

- **User** — email, passwordHash, encrypted FB creds, facebookStorageState
- **Group** — name, url, externalId, memberCount, privacy
- **Post** — content, status (DRAFT/ACTIVE/ARCHIVED), userId, media[]

### Publishing Pipeline:

- **PostGroup** — links Post to Group (many-to-many with userId)
- **PostGroupSchedule** — frequency config (ONCE/DAILY/WEEKLY/MONTHLY), nextRunAt
- **PublicationJob** — queue entry (PENDING/RUNNING/SUCCESS/FAILED/CANCELLED)
- **PublicationHistory** — record of each publish attempt with timestamps

### Support:

- **Notification** — userId, type, title, message, isRead
- **AuditLog** — action tracking
- **Subscription / Plan / UsageLimit** — future billing support

## Encryption

All sensitive data encrypted at rest using AES-256-GCM:

- Facebook App ID / App Secret (per-user)
- Facebook Storage State (cookies)

Format: `salt:iv:authTag:ciphertext` (hex-encoded, colon-separated)

Key derivation: PBKDF2 (SHA-512, 100k iterations) from `ENCRYPTION_KEY` env var.

## Error Handling

```javascript
// Route-level: asyncHandler wraps async route handlers
router.get("/path", asyncHandler(async (req, res) => { ... }))

// App-level: global error middleware in index.js
app.use((err, req, res, next) => {
  console.error(err.stack)
  res.status(500).json({ error: "Internal server error" })
})
```
